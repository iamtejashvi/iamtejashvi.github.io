# Tejashvi Portfolio

A simple static portfolio for Tejashvi, a third-year BTech Computer Science student focused on Data Structures, Algorithms, frontend development, and practical web applications. It is built with plain HTML, CSS, and JavaScript, so you can host it anywhere that serves static files.

## Customize

Edit `index.html` if you want to change:

- Project links once each repository/demo has a final URL
- Profile links if your username changes
- Project descriptions, skills, certifications, or contact text

The generated visual asset lives at `assets/minimal-mark.png`.
Your generic resume lives at `assets/Tejashvi_Resume.docx`.

## Open Locally

Open `index.html` directly in your browser.

## Put It Online

The easiest options are:

- GitHub Pages
- Netlify
- Vercel

For GitHub Pages, create a repository, upload these files, then enable Pages from the repository settings.
